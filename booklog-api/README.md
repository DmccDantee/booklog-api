# 📚 BookLog API

BookLog, Express ve MongoDB kullanılarak geliştirilmiş basit bir kitap takip API'sidir. Kitap ekleyebilir, güncelleyebilir, listeleyebilir ve silebilirsiniz.

## 🚀 Özellikler

- 📖 Tüm kitapları listeleme
- ➕ Yeni kitap ekleme
- ✏️ Kitap güncelleme
- ❌ Kitap silme

## 🛠 Kullanılan Teknolojiler

- Node.js
- Express.js
- MongoDB & Mongoose
- dotenv
- Morgan
